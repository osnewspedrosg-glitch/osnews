Sandbox de comprobaciones · sin datos personales ni médicos

Aviso de privacidad: no subas ni pegues datos personales, médicos, fotos reales ni credenciales. Usa solo datos de demostración / sandbox. Esta página no transmite resultados a ningún servidor: todo se ejecuta en el navegador y el informe JSON se descarga o copia localmente.

🎯 Para qué sirve esta página

Guía para que Grok (u otro agente) pruebe la app web publicada MAY OS · Cuidado personal de forma segura y repetible. Las comprobaciones automáticas solo verifican recursos estáticos (HTTP), presencia de APIs del navegador y la estructura demo. No validan precisión clínica, OCR médico, ni el contenido de análisis de salud.

🤖 Cómo realizar pruebas automáticas

  1. Abre esta misma página (mismo origen que la app).
  2. Pulsa Ejecutar comprobaciones. El script hace fetch GET de recursos estáticos (app.js, styles.css, vídeos, etc.) y anota el status HTTP. No sobrescribe nada.
  3. Comprueba compatibilidad de APIs (bluetooth, SpeechRecognition, mediaDevices, serviceWorker, Notifications). Nunca pide permisos automáticamente.
  4. Exporta el informe JSON (UA, fecha Europe/Madrid, estados OK / fallo / limitado).
  5. Opcional: copia el script Playwright local (abajo) y ejecútalo en tu máquina contra la URL pública. Solo usa datos demo.

Límites honestos: no se afirma precisión de salud, OCR ni Bluetooth real sin dispositivo. Esas funciones requieren datos demo y confirmación manual del usuario.
